# AI Career Intelligence System

A Python-based analytics system for exploring the AI job market using real-world job posting data.

This project demonstrates clean software architecture, object-oriented programming, dataset validation, and analytical reporting without relying on external data analysis libraries.

---

## Features

- Load AI job postings from CSV
- Validate dataset integrity
- Object-oriented Job model
- Market analysis
- Salary analysis
- Skills analysis
- Education analysis
- Demand analysis
- Export reports to:
  - JSON
  - CSV
  - Markdown

---

## Dataset

Dataset:

AI Jobs Market (2025–2026)

Contains approximately 1500 AI-related job postings including:

- Job titles
- Salaries
- Required skills
- Education
- Countries
- Remote work
- Demand score
